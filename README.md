Sebelum menjalankan proyek ini, pastikan Anda telah menginstal:

## Install Python
Unduh dan instal Python (versi 3.8 atau lebih baru) dari [python.org](https://www.python.org/downloads/). Pastikan untuk mencentang opsi **"Add Python to PATH"** saat proses instalasi.

## Install Pip
`pip` adalah package manager untuk Python yang umumnya sudah terinstal otomatis bersamaan dengan Python. Anda bisa memverifikasinya melalui terminal dengan perintah `pip --version`.

## Download & Extract Repositori
Unduh berkas repositori ini **(klik tombol Code > Download ZIP di GitHub)**. Ekstrak file ZIP yang telah diunduh ke folder komputer Anda (misalnya di folder Downloads).

## Buka Command Prompt
arahkan direktori ke folder hasil ekstrak dengan menjalankan perintah berikut:
`cd download/Aspect-Based-Sentiment-Analysis-using-naive-bayes-method`

## Install Requirements
`pip install -r requirements.txt`

## Running app
1. `py app.py` [windows]
2. `python3 app.py` [Mac/Linux]
